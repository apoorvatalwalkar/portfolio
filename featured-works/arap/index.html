Background

Context

For this project, I implemented the As-Rigid-As-Possible Surface Modeling paper to build a system for user-interactive deformation of 3D meshes. In this system, mesh vertices can be re-positioned by clicking and dragging, and the rest of the mesh updates in response so that it moves as-rigidly-as-possible, meaning the deformation stays close to a rigid transformation. The end result is a deformation that looks physically plausible, as if the mesh has an underlying rig or skeletal armature.

Understanding ARAP

ARAP is essentially a large optimization problem. It works by enforcing local rigidity, minimizing a non-linear energy function that penalizes deviations from rigid transformations between neighboring mesh elements, like triangles. At the atomic level, the paper defines rigidity as follows:

The surface of the object is covered with small, overlapping cells. An ideal deformation seeks to keep the transformation for the surface in each cell as rigid as possible.
